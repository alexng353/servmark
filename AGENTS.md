# AGENTS.md

- This is a single-package Node ESM TypeScript CLI; `src/cli.ts` is bundled by `tsup` to `dist/cli.js`.
- `dist/` is generated by `npm run build`; do not edit it by hand. The build also copies `src/style.css` into `dist/style.css`.
- Focused tests: `npx vitest run tests/server.test.ts -t "comment endpoint"`. Full tests: `npm test`.
- Typecheck explicitly with `npx tsc --noEmit`; there is no `typecheck`, `lint`, or formatter script in `package.json`.
- Before handing off code changes, run `npx tsc --noEmit`, `npm test`, and `npm run build`.
- Markdown rendering starts in `src/render.ts`; comment parsing/rendering is in `src/comment-plugin.ts`; file mutations for checkboxes/tasks/comments are in `src/mutations.ts`.
- Browser UI behavior is embedded as string scripts in `src/templates.ts`, so template tests usually assert against generated HTML rather than separate frontend files.
- Servmark comment blocks use `{::comment}` / `{:/comment}` delimiters; `relativeLines` offsets count downward from the closing delimiter, and mutation APIs address comments by source-order index.
